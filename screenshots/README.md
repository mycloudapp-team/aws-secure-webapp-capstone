# Screenshots

Evidence of what we built, organised by phase. 

## Naming
`card<NN>-<what-it-shows>-<YYYYMMDD>.pmg`
EXample: `screenshots/phase-1/card02-root-mfa-enabled-20261030.png`

## Before you upload (this repo is PUBLIC)
Hide or crop ALL of these:
-AWS account ID (12 digits) and the account sign-in URL
-Email Addresses
-Access keys, tokens, passwords, MFA or QR codes
-ARNa that contain the account ID
-Billing figure and credit balances

If something sensitve is committed by mistake, tell Bright Immediately!. Deleting the file is not enough because it stays in Git history.

## Rules
- PNG, JPG, ideally under 1 MB each.
- one screenshit per fact being proved. with a clear name.
Upload through a branch and pull request, like any other change.

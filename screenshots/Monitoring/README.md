# AWS Monitoring Documentation

## Overview
This folder contains screenshots documenting the AWS monitoring and alerting activities performed during the AWS Secure Web Application Capstone project.

## Monitoring Activities

The screenshots provide evidence of the following activities:

1. Amazon CloudWatch monitoring and metrics.
2. CloudWatch alarm configuration and monitoring.
3. Amazon SNS notification setup.
4. Monitoring alerts and notification activities.
5. AWS resource monitoring and operational visibility.

## Purpose

The purpose of this documentation is to demonstrate how AWS monitoring tools can help track resource performance, identify potential issues, and notify administrators when defined alarm conditions occur.

## AWS Services Used

- **Amazon CloudWatch:** Monitoring metrics, dashboards, and alarms.
- **Amazon SNS:** Sending notifications based on configured alert conditions.

## Evidence

The PNG files in this folder contain the screenshots captured during the monitoring setup and testing process.
